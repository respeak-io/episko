    οἶκοςoikos · the house

    Everything stays on your machine

    • No account, no Episko server. There is nothing of ours to sign in to.
    • Your Claude settings stay as they are. Each launch gets its own throwaway settings file with the hooks in it.
    • Telemetry only goes to 127.0.0.1. The hooks post to a port Episko opened on your machine.
    • Your repo gets one folder. Episko writes inside .episko/ and asks before it creates a file you would commit.

    ἐρώτησιςerōtēsis · the question

    Questions

    Is it free?

    Yes. Episko is open source under the MIT license, and there's no paid tier and no account.

    Which agents does it work with?

    Claude Code and Codex get the full cockpit: status, approvals, context and usage. About twenty other CLIs, from OpenCode to Gemini, run in a terminal pane next to them. You need at least one of them installed, because Episko starts the real CLI.

    Which systems?

    macOS on Apple silicon (signed and notarized) and Windows 10 and 11. Intel Macs and Linux aren't packaged yet.

    Does it send my code anywhere?

    No. Your agents talk to their own APIs with your own login, as they would in a terminal. Episko listens on 127.0.0.1 and has no server of its own. The only thing it fetches is the list of releases on GitHub, to tell you about updates.

    Will an update kill my running sessions?

    Not without asking. Episko tells you a new version is out and waits, because a restart would end the sessions you have open.

    Can I use it on two machines, or with a team?

    Yes, through a small sync server you run yourself: one binary and one SQLite file, or docker compose up. Settings, spend and limits follow you, and you can hand a session to the other machine. Without the server everything works the same, just locally.

    Who makes it?

    Respeak, a small company in Karlsruhe. It's written in Rust and TypeScript on Tauri, and we use it every day to build it.
