# Vendored agent extensions

Everything here except this README is generated by `scripts/vendor-integrations.mjs` from
[episko-integrations](https://github.com/respeak-io/episko-integrations): each `<id>.ts` is
that repository's `agents/<id>/episko.ts`, and `bundle.rs` is the table `protocol.rs`
compiles them in with. Their launch data lands in `src/providers/integrations.json`, whose
`source` names the commit they came from.

Change them in episko-integrations, where CI runs each inside its real agent. A daily
workflow (`.github/workflows/integrations.yml`) then opens a pull request here with the
new copies; to do it by hand:

```sh
node scripts/vendor-integrations.mjs ../episko-integrations   # its origin/main, CI must have passed
```

Editing a copy here would ship code that no agent-level test has seen, and the next
vendoring would silently undo it.
